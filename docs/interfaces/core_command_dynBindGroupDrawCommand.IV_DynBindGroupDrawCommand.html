    Type Declaration

    • OptionalbindGroups?: (undefined | null | GPUBindGroup)[]

      绑定的uniform buffer 1、GPUBindGroup，直接使用。 2、[]|undefined:忽略 3、如果有baseInfo，则忽略 则：0=system,1=entity,2=material 4、没有赋值的情况， A、按照3的情况处理； B、没有uniform bind group

    • OptionaldrawMode?: T_drawMode

      draw mode 定义 1、有值：按照 draw mode 定义了绘制的顶点数量，实例化数量，从第几个顶点开始绘制，从第几个实例开始绘制 2、无值判断是否有baseInfo.parent: A、有：从parent.getDrawModeArrayOfInstances中获取drawMode序列 B、无：判断索引模式还是非索引模式，生成drawMode序列
