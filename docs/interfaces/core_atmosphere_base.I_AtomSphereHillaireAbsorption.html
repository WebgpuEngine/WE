    Interface I_AtomSphereHillaireAbsorption

    大气中只吸收光的介质类型，包含两层。 在地球大气中，这用于模拟臭氧。

    计算公式为：

     extinction * (linearTerm * h + constantTerm),

    其中 h 是高度，linearTerm 和 constantTerm 是第一层或第二层的线性项和常数项。 如果 h 低于 AbsorptionLayer0.height，使用 Absorption.layer0，否则使用 Absorption.layer1。

    interface I_AtomSphereHillaireAbsorption {
        extinction: [number, number, number];
        layer0: { constantTerm: number; height: number; linearTerm: number };
        layer1: { constantTerm: number; linearTerm: number };
    }
